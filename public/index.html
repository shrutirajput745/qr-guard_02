Enhancement Techniques

Applied sequentially until a QR code is successfully decoded.

1
Original Decode

Direct decode attempt without any processing.

2
Grayscale Conversion

Converts color image to grayscale to reduce noise interference.

3
Contrast Enhancement

Stretches the histogram to maximize pixel value range.

4
Sharpening Filter

Applies a convolution kernel to enhance edges and fine details.

5
Adaptive Threshold (Otsu)

Binarizes the image into black and white using optimal threshold.

6
Rotation Correction

Tries 90°, 180°, and 270° rotations on the binarized image.

Limitation: Recovery works best on slightly degraded images. Severely damaged, extremely low-resolution (<50px), or partially cropped QR codes cannot be reliably recovered.

02 / 09 · PROBLEM STATEMENT

Problem Statement: Hidden Risks in Visual Codes

Visual problem-to-impact analysis of modern QR security vulnerabilities

PROBLEM 01

Opaque Destinations

Users cannot visually inspect where a QR code will take them. It is impossible for human eyes to parse a matrix before scanning.

IMPACT:
Blind trust leads users to open deceptive web destinations without prior verification.
PROBLEM 02

Unchecked URL Threats

QR codes often contain links worthy of closer inspection: plain HTTP, raw IP hosts, deceptive @ signs, and credential-harvesting tokens.

IMPACT:
Default phone camera apps auto-launch links, exposing users to quishing scams.
PROBLEM 03

Degraded Image Readability

Camera defocus, glare, motion blur, and low-contrast lighting frequently prevent barcode libraries from reading codes.

IMPACT:
Users experience silent scanning failures with no feedback or recovery avenues.
Key Observation:
A dedicated, non-intrusive client security shield is necessary to inspect QR content before handing navigation off to the web browser.

06 / 09 · TECHNICAL LOGIC

Smart Technique: Deterministic Technical Approach

Transparent, auditable cybersecurity rules without opaque black boxes or fabricated AI

TECHNIQUE 1

QR Decoding & Localization

Processes image pixel arrays on an HTML5 Canvas, identifies 3 finder pattern markers, establishes perspective coordinates, and computes Reed-Solomon error correction.

Implementation: jsQR client library · Zero server dependency
TECHNIQUE 2

Content-Dependent Handling

Detects payload schemas (http/https, WIFI:, upi://, tel:, mailto:). Applies specialized classification rendering and sanitizes suspicious schemes like javascript:.

Implementation: Deterministic schema routing & defanging
TECHNIQUE 3

9-Rule Heuristic URL Analyzer

Inspects protocol security, raw IP addresses, high-risk TLDs, phishing keywords ("login", "verify", "bank"), URL shorteners, and @ sign redirection tricks into an explainable 0–100 score.

Implementation: analyzer.js rule matrix with explainable evidence
TECHNIQUE 4

Planned Image Preprocessing

Researching digital image processing filters (3x3 unsharp convolution kernel, dynamic histogram stretching, Otsu thresholding) for recovering blurred QR codes.

Status: Under Active Development & Research Testing
